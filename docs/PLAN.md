# План проекта: Werewolf Night Survivor (VK Games)

**Рабочее название:** *Blood Moon Run* / *Ночь Оборотня*  
**Платформа:** VK Mini Apps / VK Games (HTML5)  
**Приоритет:** мобильные, книжная (portrait) ориентация  
**Референс:** *Pickle Pete* (запись + скриншоты UI/геймплея)

---

## 1. Анализ референса

### 1.1 Источники
| Источник | Что даёт |
|----------|----------|
| Видео `Запись 2026-08-05 220958.mp4` (~1.4 GB, **21:21**) | Длинный прогон геймплея (запись экрана) |
| `content.jpg`, `content (1).jpg` | Бой: HUD, джойстик, skill, волны |
| `content (2–4).jpg` | Splash/loading, аутентификация VK, вход |

> Кадры из MP4 не извлечены (нет ffmpeg/opencv в окружении). Выводы по геймплею и UI опираются на скриншоты + типовую модель жанра (top-down survivor / wave shooter), совпадающую с *Pickle Pete* на VK.

### 1.2 Жанр и петля (что копируем как механику)
- **Top-down** survival / wave shooter (родственно Vampire Survivors + active move).
- **Книжная ориентация**, камера сверху, арена/открытая зона с лёгким скроллом.
- **Виртуальный джойстик** внизу по центру — только **движение**.
- **Авто-атака / auto-aim** на ближайших врагов (игрок не целится пальцем).
- **Волны** (`ВОЛНА X/Y`) + **таймер** раунда.
- **HP-бар** (красный) + **прогресс уровня** (зелёный сегмент + номер уровня).
- **Валюта** с земли (у референса — огурцы) + счётчик.
- **Активный скилл** (круглая кнопка слева внизу, счётчик зарядов 5/8…).
- **Pause** слева сверху.
- **Враги** кучкуются, умирают с VFX (брызги), дропают лут.
- **Мета:** loading → VK auth → вход в игру (уже под VK Games).

### 1.3 UI-раскладка (эталон из скриншотов)

```
[⏸]                             
[████ HP ████] [Lv] [████ XP ████]
[🪙 N]              [ВОЛНА X/Y]
                    [MM:SS]

        … игровое поле …

[⚡ charges]          [● joystick]
```

- Скилл — **левый нижний** угол (большой hit-area).  
- Джойстик — **низ по центру**, полупрозрачный.  
- Верх — статус, не перекрывает центр боя.  
- Safe-area под вырезы iPhone / gesture bar Android.

### 1.4 Что **не** копируем 1-в-1
- Бренд, персонаж-огурец, ассеты, название, уникальный арт *Pickle Pete*.
- Точные формулы баланса — делаем свои под «оборотня».

## 2. Концепция: «Выживание оборотня»

### 2.1 Высокоуровневый питч
> Ты — оборотень под кровавой луной. Каждую ночь на тебя идут охотники, селяне и священники. Двигайся джойстиком, когти и укус бьют **сами**, прокачивайся между волнами, срывайся в **звериную форму** — и доживи до рассвета.

**Аналог механики Pickle Pete**, **уклон сеттинга** — werewolf survival (horror-comedy или dark fantasy, cartoon 2D).

### 2.2 Фантазия игрока
| Референс | Наша игра |
|----------|-----------|
| Зелёный боец с пушкой | Оборотень (человек → волк / гибрид) |
| Серые блобы | Охотники, селяне, псы, священники, серебряные рыцари |
| Огурцы-валюта | **Лунные осколки** / кровь / «сущность» |
| Скилл с зарядами | **Вой**, **Рывок**, **Трансформация** |
| Волны 1/10 | **Ночи / фазы луны** (10–15 за ран) |
| Авто-стрельба | **Авто-атака когтями / укусом / лунными снарядами** |

### 2.3 Уникальный крюк (отличие от клона)
1. **Шкала Луны / Зверя** — заполняется убийствами; на пике — **Transform** (сила↑, контроль/HP trade-off).  
2. **Серебро** — особый урон от «серебряных» врагов/пуль (надо уклоняться / приоритет цели).  
3. **Рассвет** — финал рана: босс «Охотник» или таймер рассвета; цель — **выжить**, не только зачистить.  
4. **Голод** (опционально в v1.1) — если не убиваешь, форма слабеет (pressure).

### 2.4 Тональность
- Cartoon 2D (как референс: читаемые силуэты, жирные контуры) — **лучше для мобилок и VK**, чем ультра-реализм.  
- Допустима тёмная палитра: ночной лес, луна, багровые акценты, серые/синие враги.

## 3. Геймдизайн (GDD-core)

### 3.1 Core loop (1 сессия 3–8 мин)
```
Меню → Старт ночи → Движение + авто-бой →
Убийства → XP / лут → Level-up (выбор 1 из 3) →
Конец волны → (магазин / передышка) →
След. волна → … → Рассвет / смерть →
Награды (валюта, прогресс) → Мета-апгрейды
```

### 3.2 Управление (mobile-first)
| Ввод | Действие |
|------|----------|
| Virtual joystick (низ-центр) | Перемещение 360° |
| Авто | Приоритет цели: nearest → elite → silver threat |
| Кнопка скилла (низ-лево) | Активка (charges / cooldown) |
| (Опц.) кнопка Transform | Если отделена от скилла |
| Pause | Меню / выход / звук |

**Правило:** одной рукой (большой палец — джойстик, другой / тот же — скилл). Не требовать aim-стик.

### 3.3 Бой
- **Базовая атака:** melee cone / short projectile (когти) с auto-retarget.  
- **Upgrade tree in-run:** скорость атаки, радиус, мульти-удар, орбитальные «лунные клыки», AOE-вой, lifesteal, щит из шерсти и т.д.  
- **i-frames** на рывке (короткие).  
- **Knockback** слабый, чтобы не ломать читаемость толпы.

### 3.4 Волны / контент MVP
| Волна | Фокус |
|-------|--------|
| 1–2 | Слабые селяне, обучение |
| 3–4 | Псы (быстрые), лукники (дистанция) |
| 5 | Мини-босс: Капитан охоты |
| 6–8 | Смешанные, «серебряные» пули |
| 9 | Элиты + давление |
| 10 | Босс: Серебряный Паладин / Рассвет |

**Карта:** одна arena-biome «Ночной лес / деревня» + parallax moon.  
Позже: болото, кладбище, разорённый монастырь.

### 3.5 Level-up (in-run)
Каждые N XP — **3 карточки**, pick 1 (рогалик).  
Категории: Offense / Defense / Utility / Form (зверь).

### 3.6 Мета-прогресс (между ранами)
- Дерево перков: старт. HP, скорость, +1 charge, удача дропа.  
- Разблокировка скиллов и «аспектов» оборотня (Skin).  
- Ежедневный/еженедельный вызов (для retention VK).

### 3.7 Экономика
| Ресурс | Где | На что |
|--------|-----|--------|
| Soft: Лунные осколки | Дроп + конец рана | Мета-апгрейды |
| Hard (опц.): Клыки / VK votes | IAP / ads reward | Скины, 2× soft, continue |
| Tickets (опц.) | Ежедневно | Быстрый старт / ивент |

### 3.8 Fail / Continue
- Смерть → экран статистики + **Continue** (реклама rewarded / hard currency) — стандарт VK Games.

## 4. UX / экраны (mobile portrait)

1. **Splash** — логотип, луна, силуэт волка.  
2. **VK Auth / Loading** (как «Аутентификация» / «Вход в игру» у референса).  
3. **Main menu** — Играть, Апгрейды, Скины, Настройки, Лидерборд VK.  
4. **HUD боя** — копия раскладки референса (см. §1.3), своя графика.  
5. **Level-up modal** — 3 карточки, крупные тач-зоны.  
6. **Wave clear / Shop** — короткий, не больше 5–8 сек.  
7. **Death / Victory** — share score в VK.  
8. **Pause** — продолжить / звук / в меню.

**Целевые разрешения:** 390×844 baseline; scale UI в logical units; test 360×640 … 430×932.

## 5. Технический стек (VK Games)

### 5.1 Рекомендация
| Слой | Выбор | Почему |
|------|--------|--------|
| Runtime | **HTML5** (WebView / iframe) | Натив для VK Mini Apps |
| Движок | **Phaser 3** *или* **PixiJS + собственный loop** | 2D, joystick, throngs, WebGL |
| Язык | **TypeScript** | Надёжность |
| UI меню | HTML/CSS overlay *или* in-canvas | Меню — HTML быстрее; HUD — canvas |
| VK | `@vkontakte/vk-bridge` | Auth, ads, storage, share, payments |
| Бэкенд MVP | **Без** или лёгкий (Cloud Functions / VPS) | Сейвы: `VKWebAppStorage` + опц. сервер |
| Сборка | Vite | Быстрый dev |
| Хостинг | HTTPS static (VK app URL) | Требование платформы |

**Альтернатива:** Unity WebGL — тяжелее по размеру/старту на mid-end Android; для hyper-casual throngs Phaser/Pixi обычно выгоднее.

### 5.2 Интеграции VK Bridge (минимум)
- `VKWebAppInit`
- User info / launch params
- `VKWebAppShowNativeAds` / rewarded (continue, 2× reward)
- `VKWebAppStorageSet/Get` (прогресс)
- `VKWebAppShare` / wall post (скор)
- Платежи (IAP) — после MVP soft-loop
- Orientation: **force portrait** в настройках приложения + CSS `portrait`

### 5.3 Производительность (критично)
- Object pool: пули, враги, VFX, дроп.  
- Лимит активных врагов (напр. 80–120) + spawn queue.  
- Простая коллизия: circle vs circle.  
- Spatial hash / grid для nearest-target.  
- 30–60 FPS target на mid Android.  
- Атласы спрайтов, сжатие WebP/ASTC где возможно.  
- Размер билда: стремиться **&lt; 15–25 MB** initial.

### 5.4 Структура репозитория (черновик)
```
/apps/game          # Phaser/TS клиент
  /src/scenes       # Boot, Menu, Run, UI
  /src/systems      # Combat, Waves, XP, Economy
  /src/entities     # Player, Enemy, Projectile, Drop
  /src/ui           # Joystick, HUD, Cards
  /src/vk           # Bridge wrappers
/assets             # atlases, audio
/docs               # GDD, balance sheets
```

## 6. Арт / аудио

### 6.1 Стиль
- 2D cartoon, thick outline, читаемость на 5" экране.  
- Палитра: deep blue-green night, bone grey, blood crimson, moon silver.  
- Персонаж: 1 idle, walk 4–6, attack, transform morph (короткий).

### 6.2 MVP-набор ассетов
- Player (humanoid-wolf) + 1 transform skin  
- 4 типа врагов + 1 босс  
- 1 tileset / ground pattern + props (пни, камни, забор)  
- UI kit: bars, joystick, skill button, cards, icons  
- FX: slash, blood/moon splash, level-up, death  
- SFX: hit, howl, pickup, UI; 1 music loop night  

### 6.3 Источники
- Собственная генерация (Imagine / artist) + ручная полировка под атлас.  
- Не использовать ассеты Pickle Pete.

## 7. Монетизация (VK)

| Метод | Когда | Заметка |
|-------|-------|---------|
| Rewarded ads | Continue, 2× награда, доп. reroll карточек | Основной ARPU early |
| Interstitial | Между ранами (лимит частоты) | Не после каждой смерти |
| Soft economy | Всегда | Прогресс без paywall skill |
| IAP скины / battle pass | Post-MVP | Косметика first |
| VK community / share | Viral | Бонус soft за share |

**Fair play:** power IAP не обязателен для прохождения волны 10.

## 9. Метрики успеха (soft launch)
- D1 retention ≥ 25–30%  
- Avg session ≥ 4 мин  
- Wave 5 reach ≥ 40% новых  
- Ad opt-in (rewarded) ≥ 0.3–0.6 / session  
- Crash-free ≥ 99%

## 10. Риски и смягчение
| Риск | Митигация |
|------|-----------|
| «Клон» / IP | Свой арт, lore, названия; механики жанра — не защищены, бренд — да |
| FPS throng на слабых Android | Pooling, cap enemies, simplify FX |
| Отклонение модерации VK | Нет жестокого gore; cartoon blood; age rating |
| Pay-to-win backlash | Cosmetics + convenience, не must-have power |
| Выгорание скоупа | Жёсткий MVP: 1 биом, 10 волн, 1 transform |

---

## 11. Критерии готовности MVP
1. Стабильный портретный запуск в клиенте VK (iOS + Android).  
2. Полный ран: 10 волн → босс или поражение.  
3. Джойстик + автобой + 1 скилл + level-up.  
4. Мета: 5–8 постоянных апгрейдов.  
5. Rewarded continue.  
6. Сохранение прогресса между сессиями.  
7. Нет блокирующих багов на mid-device.
